Privacy

CabCount publishes a tracker of Robotaxi information that is already public. It does not ask visitors for an email address, an account, a sighting report, or other personal details.

What you can do here

You can read the pages, move the map, and open a city. The city list and charts are drawn from files on this site. There is no search box, account, or form, so the pages have no field that submits what you type.

What a visit can still create

  • Host logs. The site is hosted on Cloudflare. A request can be recorded in Cloudflare access and security logs, including IP address, user agent, the URL, and the time. This repository cannot turn those logs off.
  • Network-error reporting. Cloudflare may add network-error reporting headers on responses. This site does not set those headers, and it cannot remove headers the host adds.
  • Web Analytics tag. Cloudflare Pages can insert a Cloudflare Web Analytics script on the live site. That script is not part of this repository. Responses include a Content Security Policy that allows scripts and network calls only back to this site, plus map images from OpenStreetMap. A browser that enforces that policy should refuse the analytics script. Turning the tag off entirely is a Cloudflare project setting, not a change in this repository.
  • Map images. The homepage map loads tiles from OpenStreetMap (tile.openstreetmap.org). Your IP address, the map area you view, and this site's address as the referrer are sent to OpenStreetMap so those images can be drawn. Links to sources, Beam42, YouTube, and OpenStreetMap load those sites only if you follow them. Page scripts and styles are files on this site.

This page does not say that a visit creates no data. CabCount does not ask you to submit information. Hosting logs, map tiles, and a host-inserted analytics tag can still involve another party.

CabCount is an independent tracker. Not affiliated with Tesla, Inc. Fleet numbers are registrations; service areas are estimates.
