Privacy

What this version of cabcount.app does with information, and what this repository cannot confirm.

Last updated: November 6, 2026

This page describes the site. It is not a claim that CabCount complies with any particular privacy law.

Who we are

CabCount (cabcount.app) is an independent tracker of Tesla Robotaxi and Cybercab rollout, published by Beam42. CabCount is not affiliated with Tesla, Inc.

This page covers cabcount.app only.

Sighting submissions

The sightings page embeds a form hosted by Tally at tally.so/r/7XlGB6. On November 6, 2026 that public form asked for:

  • City (required text)
  • Date seen (required date)
  • What did you see? (required choice): Tesla Robotaxi with no driver, Robotaxi with safety monitor, Cybercab, Test vehicle with sensors, or Other
  • Details (optional text, so it can include whatever you type)
  • Photo or video link (optional). This is a link, not a file upload.
  • Your email (optional), with the form note “Only if we may follow up.”

The submission is stored by Tally. This repository has no database and no copy of Tally responses. Published city pages are generated from the site data file, which does not include a submitter email. The sightings page says a person reviews a submission before it is added to the map. There is no review queue in this repository; adding a sighting to the map means editing that data file.

Tally’s own retention, cookies, and access controls are not visible from this repository.

Email lists

Mailing lists are paused. This version of the site has no email signup form and does not send newsletters.

The site published before this change included a Kit form, id 10069322, that posted an email address and an optional city to Kit. This repository cannot confirm whether anyone used that form, or whether Kit still holds those addresses. Removing the form does not delete anything Kit may already have. Unpublished newsletter drafts in the repository are not a signup and are not sent by this site.

Map tiles

The homepage map is drawn with Leaflet, a script hosted on cabcount.app. The map images are requested from OpenStreetMap at tile.openstreetmap.org. Your browser sends that request, including your IP address, to OpenStreetMap. Chart.js is also a file on cabcount.app. The site does not load fonts from a third party.

Hosting and Cloudflare Web Analytics

Cloudflare Pages serves the site. A request to the live site on November 6, 2026 included Cloudflare response headers. Those headers included a Network Error Logging report-to entry that this repository’s _headers file does not set. The same HTML included a script Cloudflare injects: https://static.cloudflareinsights.com/beacon.min.js.

That beacon is not stored in this repository. Cloudflare’s documentation says the Web Analytics beacon does not use cookies or localStorage, and that it does not collect visitors’ personal data. The same documentation says the service receives the client IP address as part of the HTTP request and discards that IP at the nearest data center. We have not audited the beacon, and this repository cannot confirm the Cloudflare dashboard setting, including whether visits from the EU are excluded.

This repository does not include a session-recording script. Cloudflare may keep its own connection logs. We do not copy those logs into a CabCount database, and we do not set their retention period.

What the repository does not do

  • There is no CabCount account system.
  • The site’s own JavaScript does not set a cookie. Pages embedded from Tally, requests to OpenStreetMap, and Cloudflare’s own responses can still set cookies. A check of the homepage response headers on November 6, 2026 did not include Set-Cookie. That single check is not a promise that no cookie is ever set.
  • Nothing in this repository sells visitor or submission data.

Deletion requests

Email the privacy contact and identify the sighting, for example by the page URL or the email address on the submission. We can edit or remove text that is published as files on this site. We can ask Tally to delete its copy. Whether Tally deletes it is not something this repository can confirm. We may keep a short note that a request arrived. We may be unable to tell which record is yours.

Not for children under 13

CabCount is not aimed at children under 13. Do not submit a sighting or an email address if you are under 13. The Tally form in this repository has no age check. If you believe a child under 13 has sent personal information, email the privacy contact and we will remove published material we can identify and ask Tally to delete the submission.
